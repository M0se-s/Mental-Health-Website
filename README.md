# Mental Health Website

A simple, responsive **static** mental health landing page built with **HTML + CSS**.  
The homepage highlights a supportive message, a navigation menu, and a “Schedule an Appointment” call-to-action over a background image.

## Built With
- **HTML5**
- **CSS3**
- **Google Fonts** (Inter, Red Hat Display)

## Project Files
Typical structure for this project:

- `index.html` — main page
- `styles.css` — site styling
- `images/` — image assets  
- `Rectangle 6.png` — background image used on the page

## Run Locally
No installation required.

1. Clone the repo:
   ```bash
   git clone https://github.com/M0se-s/Mental-Health-Website.git
   ```
2. Open the folder.
3. Open `index.html` in your browser (double click it or use “Open with”).

## Notes
- The page background is set in CSS using:
  - `background-image: url('images/Rectangle 6.png');`
- If the background does not load, confirm:
  - the file exists at `images/Rectangle 6.png`
  - capitalization/spaces in the filename match exactly
